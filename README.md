# moncourtier.quebec

Site vitrine (maquette) de moncourtier.québec : relevé de propriété pour les courtiers immobiliers du Québec.

- `index.html` : le site complet en un seul fichier (HTML, CSS et JavaScript).
- Aucune dépendance à installer. Les polices viennent de Google Fonts.
- La balise `noindex` empêche le référencement tant que le site est une maquette. La retirer au lancement.

## Mise en ligne sur OVH

1. Espace client OVH > Web Cloud > Hébergements > Mes sites.
2. Menu du site > Associer Git : adresse du dépôt, branche `main`.
3. Déployer Git.

## État

Les données affichées sont fictives. La recherche, les comptes et le paiement ne sont pas branchés.
